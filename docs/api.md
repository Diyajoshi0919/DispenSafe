# DispenSafe API

Base URL: `http://<server-ip>:8000`. Interactive docs: `/docs` (auto-generated by FastAPI).

All request and response bodies are JSON unless stated. Times are Unix timestamps (seconds).

## Authentication

| Who | How |
|---|---|
| Print agent | Header `X-Agent-Key: <AGENT_KEY>` |
| OPD and pharmacy staff | Log in with `POST /api/auth/login`. The server sets an HttpOnly cookie `ds_session` (12 hours); the browser sends it automatically. |
| Student confirm page | No login; the one-time QR token is the permission |

Roles: an `opd` account can use OPD endpoints, a `pharmacy` account can use pharmacy endpoints,
an `admin` account can use both. Wrong role returns **403**, not logged in returns **401**.

| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/api/auth/login` | `{ username, password }` | `{ name, role }` and the session cookie. **401** wrong details, **429** after 5 wrong attempts (15 min lock). |
| POST | `/api/auth/logout` | | `{ ok }` |
| GET | `/api/auth/me` | | `{ id, name, role, username }` or **401** |

Staff actions (approve, reject, hand over, new QR) are recorded in `audit_log` under the
logged-in person's name. Prescriptions record the logged-in doctor as `doctor_id`.

## Bill object

Returned by most endpoints.

```json
{
  "id": 2, "bill_no": "4522", "job_id": "20261114-104700-ab12cd",
  "roll_no": "22104118", "total": 95.0,
  "status": "pending",
  "reject_reason": null, "raw_text": "...", "replaces_bill_id": null,
  "created_at": 1794671476.9, "updated_at": 1794671476.9,
  "items": [{ "medicine_name": "Pantoprazole 40mg", "qty": 10, "amount": 65.0 }],
  "student": { "name": "Aman Verma", "programme": "B.Tech ECE" }
}
```

`status` moves only forward: `pending` → `approved` or `rejected`; `approved` → `confirmed`; `confirmed` → `handed_over`. Any other change returns **409**.

## Print agent

| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/api/bills` | `{ job_id, roll_no, bill_no?, items: [{name, qty, amount}], total?, raw_text? }` | Bill. Same `job_id` again returns the existing bill (no duplicate). |

## OPD (logged in as opd or admin)

| Method | Path | Body | Returns |
|---|---|---|---|
| GET | `/api/opd/bills?status=pending` | | Bills from the last 24 h. `status` can be a comma list. |
| GET | `/api/opd/bills/{id}` | | `{ bill, prescription, not_on_prescription: [names], activity: [...] }` |
| POST | `/api/opd/bills/{id}/approve` | | Bill. Creates the QR token. |
| POST | `/api/opd/bills/{id}/reject` | `{ reason }` | Bill. **400** if `reason` is empty. |
| POST | `/api/opd/prescriptions` | multipart form: `roll_no`, `notes`, `items` (JSON list of `{medicine_name, dose}`), `photo` (optional) | `{ id }` |

## Pharmacy (logged in as pharmacy or admin)

| Method | Path | Body | Returns |
|---|---|---|---|
| GET | `/api/pharmacy/bills` | | All bills from the last 24 h |
| GET | `/api/pharmacy/bills/{id}/qr.svg` | | SVG image. Makes a new token if the old one expired. **409** unless approved. |
| POST | `/api/pharmacy/bills/{id}/new-qr` | | `{ ok }`. Old QR stops working. |
| POST | `/api/pharmacy/bills/{id}/handover` | | Bill. Only from `confirmed`. |

## Student (QR token)

| Method | Path | Body | Returns |
|---|---|---|---|
| GET | `/api/confirm/{token}` | | `{ bill_no, roll_no (masked), items, total }`. **404** if expired or used. |
| POST | `/api/confirm/{token}` | `{ roll_no }` | `{ ok }`. **403** if the roll number does not match. Token is single-use. |

## Home page (public)

| Method | Path | Returns |
|---|---|---|
| GET | `/api/home` | `{ opd_open, doctor_on_duty, pharmacy_hours, bills_waiting, emergency_phone, notices: [text] }` |

## Live updates

WebSocket at `/ws` (logged-in staff only; others are disconnected). Each message: `{ "event": "...", "data": <bill> }`.

Events: `bill_created`, `bill_approved`, `bill_rejected`, `bill_confirmed`, `bill_handed_over`.
Pages should send `"ping"` every ~25 s and reconnect after 2 s if the connection drops.
